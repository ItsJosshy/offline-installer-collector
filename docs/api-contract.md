# API contract
All JSON uses camelCase. Errors are `{error:string}`. Authenticated API cookie and `X-CSRF-TOKEN` header for every mutation, including login/setup. GET /api/auth returns `{authenticated,setupRequired,csrfToken,username}`. POST /api/auth/setup `{username,password,setupSecret}`; POST /api/auth/login `{username,password}`; POST /api/auth/logout `{}`. Refresh auth response after sign-in.

GET /api/state returns `{apps,sources,variants,files,jobs,libraries,settings,capabilities}` matching Domain.cs; each library adds `accessible,freeBytes`. GET /api/directories?path=encoded => `{path,parent,roots:string[],directories:[{name,path}],error?}`; no path lists allowed roots. POST /api/libraries `{path}` selects existing directory, returns library. POST /api/scan `{}` queues scan of active library.

GET /api/providers/{id}/search?q=... => ProviderHit[]. POST /api/providers/{id}/preview ProviderQuery => ProviderResult (no tracking). POST /api/apps `{provider,identifier,channel,assetFilter,metadataUrl,selectedKeys:string[],appId?:string}` resolves again and persists selected variants (may add source to existing app). POST /api/apps/{id}/check `{download:boolean}` queues check; id `all` checks all. PATCH /api/apps/{id} `{paused,keepVersions,name}`. PATCH /api/variants/{id} `{tracked}`. POST /api/variants/{id}/download `{}`. POST /api/jobs/{id}/cancel `{}`.

PATCH /api/files/{id} `{appId?:string,managed?:boolean,pinned?:boolean,name?:string,version?:string,os?:string,architecture?:string,artifactType?:string,offlineTestNotes?:string,offlineTestEnvironment?:string,offlineTestDate?:string}`. GET /api/files/{id}/download authenticated attachment. POST /api/files/{id}/delete `{confirmPath:string}` explicit exact-path confirmation. GET /api/manifest exports versioned tracking. POST /api/manifest imports JSON exported manifest, never filesystem paths or credentials. GET /api/backup downloads consistent SQLite backup. PUT /api/settings `{concurrency,scheduleEnabled,checkHour,timezone}`. Host-only allowed paths and credentials appear as configuration status, never secrets; restart to change environment settings.

SignalR /hubs/progress sends `changed` (refetch /api/state) and may send `progress` Job. Client must refetch on reconnect and poll fallback every 5 seconds. Queries require auth except /api/auth and health. Dates UTC ISO strings. Available/Tracked/Archived are separate, archived requires !missing file.

Core service contracts for jobs: PathGuard.Validate(string,bool=true); PathGuard.ForLibrary(Library,string,bool=true); PathGuard.AssertLibrary(Library) verifies sentinel; Scanner.ScanAsync(Library,CancellationToken) scoped service; ProviderRegistry.Get(string) returns IProvider. Jobs expose JobQueue.EnqueueAsync(kind,library,appId?,variantId?,payload?,ct), CancelAsync(id,ct); CheckService.CheckAsync(appId,download,library,ct). Worker registers as hosted service. ProgressHub in InstallerVault.Jobs. Jobs can implement alternative signatures and report them for API wiring.
